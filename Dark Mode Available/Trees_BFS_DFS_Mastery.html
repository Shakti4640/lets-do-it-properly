① What is a Tree? (Imagine a family tree, upside-down)

A tree is just a bunch of boxes (called nodes) connected by lines. The top box is called the root. Every box can point to children below it. A box with no children is called a leaf — like a real leaf at the tip of a branch.

1 ← root / \ 2 3 / \ \ 4 5 6 ← 4, 5, 6 are leaves

A Binary Tree means every box has at most 2 children: a left and a right. That's the kind we'll work with 99% of the time.

Why trees? Folders on your computer, the HTML on this page, family genealogy, Git commits, decision flowcharts — all trees. Mastering them unlocks a huge category of interview problems.

Tree vocabulary you must know

RootThe single top node. Has no parent. Parent / ChildIf A points down to B, A is the parent of B. LeafA node with no children (both left and right are null). Depth of a nodeHow many edges from the root down to it. Root depth = 0. Height of a nodeHow many edges from the node down to its deepest leaf. SubtreeAny node + everything below it forms its own little tree. LevelAll nodes at the same depth. Level 0 = root, level 1 = root's kids, etc.

② The TreeNode class — our building block

Almost every Java tree problem on LeetCode uses this exact class. Memorize it:

public class TreeNode {
    int val;            // the number stored in this box
    TreeNode left;      // pointer to the left child (or null)
    TreeNode right;     // pointer to the right child (or null)

    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

Think of each TreeNode as a Lego brick with three slots: a number, a left socket, and a right socket. You snap bricks together by setting left and right to other bricks.

③ Building a Tree by hand

Let's build this exact tree in Java:

1 / \ 2 3 / \ 4 5 
TreeNode root = new TreeNode(1);
root.left  = new TreeNode(2);
root.right = new TreeNode(3);
root.left.left  = new TreeNode(4);
root.left.right = new TreeNode(5);

That's it. root now holds the entire tree because every node chains to the next via left/right.

Bonus: Build a tree from a level‑order array (LeetCode style) 
// Input like [1,2,3,4,5,null,6] — same way LeetCode shows trees
public static TreeNode build(Integer[] arr){
    if (arr.length == 0 || arr[0] == null) return null;
    TreeNode root = new TreeNode(arr[0]);
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    int i = 1;
    while (!q.isEmpty() && i < arr.length){
        TreeNode cur = q.poll();
        if (i < arr.length && arr[i] != null){
            cur.left = new TreeNode(arr[i]); q.add(cur.left);
        }
        i++;
        if (i < arr.length && arr[i] != null){
            cur.right = new TreeNode(arr[i]); q.add(cur.right);
        }
        i++;
    }
    return root;
}

④ The 4 traversals (the ABCs of trees)

"Traversal" just means visit every node once, in some order. There are 4 famous ones. Three of them are DFS (deep-first), one is BFS (level-by-level).

1 / \ 2 3 / \ 4 5
Preorder DFS  Root → Left → Right
Visit order: 1 → 2 → 4 → 5 → 3
Inorder DFS  Left → Root → Right
Visit order: 4 → 2 → 5 → 1 → 3
In a BST this gives sorted output ✨
Postorder DFS  Left → Right → Root
Visit order: 4 → 5 → 2 → 3 → 1
Great when you need info from children before deciding the parent.
Level Order BFS  Top → Bottom, Left → Right
Visit order: 1 → 2 → 3 → 4 → 5

The DFS template (recursion = magic)

void dfs(TreeNode node){
    if (node == null) return;     // 🛑 base case — fell off the tree
    // preorder: do work HERE
    dfs(node.left);
    // inorder:  do work HERE
    dfs(node.right);
    // postorder: do work HERE
}
Mental model: Recursion is just "trust your future self". You assume the recursive call already does the right thing for the subtree, and you just figure out what to do at the current node.

The BFS template (queue = waiting line)

void bfs(TreeNode root){
    if (root == null) return;
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    while (!q.isEmpty()){
        int size = q.size();           // freeze how many are at THIS level
        for (int i = 0; i < size; i++){
            TreeNode cur = q.poll();
            // do work with cur
            if (cur.left  != null) q.add(cur.left);
            if (cur.right != null) q.add(cur.right);
        }
    }
}

The size trick is gold: it lets you process the tree level by level. Remember it — most BFS problems use it.

⑤ BFS Track 🚂 — Very Easy → Hard

BFS = "explore the tree in layers, like ripples in a pond." Always reach for a Queue. Whenever a problem mentions level, row, shortest, nearest, or view, BFS is usually the move.

VERY EASY B1. Level Order Traversal (LC 102)

Problem: Return a list of lists. Each inner list = nodes on that level, left to right.

3 / \ 9 20 / \ 15 7

Output: [[3],[9,20],[15,7]]

Intuition

Use the queue trick. At each round of the while loop, every node in the queue is on the same level — so empty all of them, collect their values, and push their kids in.

Java

public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> ans = new ArrayList<>();
    if (root == null) return ans;
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    while (!q.isEmpty()){
        int size = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i=0; i<size; i++){
            TreeNode cur = q.poll();
            level.add(cur.val);
            if (cur.left  != null) q.add(cur.left);
            if (cur.right != null) q.add(cur.right);
        }
        ans.add(level);
    }
    return ans;
}
TimeO(n) — visit every node once. SpaceO(n) — queue holds at most one full level (~n/2 in a balanced tree).

EASY B2. Average of Levels (LC 637)

Problem: Return the average value of the nodes on each level.

Twist on B1: Instead of collecting values into a list, sum them and divide by size.

public List<Double> averageOfLevels(TreeNode root) {
    List<Double> ans = new ArrayList<>();
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    while(!q.isEmpty()){
        int size = q.size();
        double sum = 0;          // use double — sum can overflow int!
        for (int i=0; i<size; i++){
            TreeNode c = q.poll();
            sum += c.val;
            if (c.left  != null) q.add(c.left);
            if (c.right != null) q.add(c.right);
        }
        ans.add(sum / size);
    }
    return ans;
}
Trap: If you use int sum, two huge nodes (e.g. Integer.MAX_VALUE) overflow. Always double or long for sums in tree problems.

EASY B3. Find Bottom-Left Tree Value (LC 513)

Problem: Return the value of the leftmost node on the deepest level.

Intuition

BFS shines here. The first node you pop on each level is the leftmost node of that level. So just keep updating an answer with the first node of each level — when BFS ends, answer is the leftmost on the deepest level.

public int findBottomLeftValue(TreeNode root) {
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    int ans = root.val;
    while (!q.isEmpty()){
        int size = q.size();
        for (int i=0; i<size; i++){
            TreeNode c = q.poll();
            if (i == 0) ans = c.val;     // first of this level
            if (c.left  != null) q.add(c.left);
            if (c.right != null) q.add(c.right);
        }
    }
    return ans;
}
🧠 Even slicker trick

Push right child before left, and the very last node you pop is automatically the bottom-left! No size loop needed.

MEDIUM B4. Binary Tree Right Side View (LC 199)

Problem: Imagine standing on the right side of the tree. Return the values you see from top to bottom — i.e., the rightmost node of every level.

1 ← see 1 / \ 2 3 ← see 3 \ \ 5 4 ← see 4

Output: [1,3,4]

Intuition

BFS level by level. On each level, take the last node (i.e., when i == size-1).

public List<Integer> rightSideView(TreeNode root) {
    List<Integer> ans = new ArrayList<>();
    if (root == null) return ans;
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    while(!q.isEmpty()){
        int size = q.size();
        for (int i=0; i<size; i++){
            TreeNode c = q.poll();
            if (i == size - 1) ans.add(c.val);
            if (c.left  != null) q.add(c.left);
            if (c.right != null) q.add(c.right);
        }
    }
    return ans;
}

MEDIUM B5. Zigzag Level Order (LC 103)

Problem: Like B1, but reverse direction every other level: L→R, then R→L, then L→R...

Output for the earlier tree: [[3],[20,9],[15,7]]

Intuition

Do regular BFS. On "reverse" levels, just reverse the list before adding to the answer. Tracking with a boolean leftToRight is cleanest.

public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> ans = new ArrayList<>();
    if (root == null) return ans;
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    boolean leftToRight = true;
    while(!q.isEmpty()){
        int size = q.size();
        LinkedList<Integer> level = new LinkedList<>();
        for (int i=0; i<size; i++){
            TreeNode c = q.poll();
            if (leftToRight) level.addLast(c.val);
            else             level.addFirst(c.val);   // O(1) — that's why LinkedList
            if (c.left  != null) q.add(c.left);
            if (c.right != null) q.add(c.right);
        }
        ans.add(level);
        leftToRight = !leftToRight;
    }
    return ans;
}
Why LinkedList? addFirst is O(1) on a LinkedList; on an ArrayList it would be O(n). Tiny detail, big speedup.

MEDIUM B6. Populate Next Right Pointers (LC 116)

Problem: You're given a perfect binary tree. Each node has a next pointer. Connect each node to the node immediately right of it on the same level. Last node of each level points to null.

Intuition

BFS level by level. Within a level, just chain prev.next = current as you pop nodes.

public Node connect(Node root) {
    if (root == null) return null;
    Queue<Node> q = new LinkedList<>();
    q.add(root);
    while(!q.isEmpty()){
        int size = q.size();
        Node prev = null;
        for (int i=0; i<size; i++){
            Node c = q.poll();
            if (prev != null) prev.next = c;
            prev = c;
            if (c.left  != null) q.add(c.left);
            if (c.right != null) q.add(c.right);
        }
        // prev is the last node of the level — its .next stays null ✅
    }
    return root;
}

HARD B7. Serialize and Deserialize Binary Tree (LC 297)

Problem: Convert a tree → a String, and back. So we can save trees to disk or send over a network.

Intuition

Use BFS. Walk the tree level-order, writing each value separated by a comma. Use the placeholder "#" for null. To rebuild, do BFS again: read tokens in pairs, snapping each pair under the next node from the queue.

public class Codec {
    public String serialize(TreeNode root){
        if (root == null) return "";
        StringBuilder sb = new StringBuilder();
        Queue<TreeNode> q = new LinkedList<>();
        q.add(root);
        while(!q.isEmpty()){
            TreeNode c = q.poll();
            if (c == null){ sb.append("#,"); continue; }
            sb.append(c.val).append(',');
            q.add(c.left);   // null is fine — we encode it as "#"
            q.add(c.right);
        }
        return sb.toString();
    }

    public TreeNode deserialize(String data){
        if (data.isEmpty()) return null;
        String[] t = data.split(",");
        TreeNode root = new TreeNode(Integer.parseInt(t[0]));
        Queue<TreeNode> q = new LinkedList<>();
        q.add(root);
        int i = 1;
        while (!q.isEmpty() && i < t.length){
            TreeNode p = q.poll();
            if (!t[i].equals("#")){
                p.left = new TreeNode(Integer.parseInt(t[i]));
                q.add(p.left);
            }
            i++;
            if (i < t.length && !t[i].equals("#")){
                p.right = new TreeNode(Integer.parseInt(t[i]));
                q.add(p.right);
            }
            i++;
        }
        return root;
    }
}
Why this matters: Serializing trees is the foundation for things like sending JSON across the internet, saving game states, or how databases store B‑Trees on disk.

HARD B8. Vertical Order Traversal (LC 987)

Problem: Group nodes by their x‑coordinate (column). Root is at col 0, left child is col-1, right child is col+1. Return columns in order. Within a column, sort by row, then by value.

Intuition

BFS while carrying (node, row, col). Group by col in a TreeMap so columns auto-sort. Within a column, sort entries by row, then value.

public List<List<Integer>> verticalTraversal(TreeNode root) {
    // col -> list of (row, val)
    TreeMap<Integer, List<int[]>> map = new TreeMap<>();
    Queue<Object[]> q = new LinkedList<>();
    q.add(new Object[]{root, 0, 0});       // node, row, col
    while(!q.isEmpty()){
        Object[] cur = q.poll();
        TreeNode n = (TreeNode) cur[0];
        int r = (int) cur[1], c = (int) cur[2];
        map.computeIfAbsent(c, k -> new ArrayList<>()).add(new int[]{r, n.val});
        if (n.left  != null) q.add(new Object[]{n.left,  r+1, c-1});
        if (n.right != null) q.add(new Object[]{n.right, r+1, c+1});
    }
    List<List<Integer>> ans = new ArrayList<>();
    for (List<int[]> col : map.values()){
        col.sort((a,b) -> a[0] != b[0] ? a[0]-b[0] : a[1]-b[1]);
        List<Integer> vals = new ArrayList<>();
        for (int[] e : col) vals.add(e[1]);
        ans.add(vals);
    }
    return ans;
}
Pattern to remember: "Carry extra info along with the node in the queue" — coordinates, depth, parent pointer, you name it. The queue can hold tuples, not just nodes.

⑥ DFS Track 🪂 — Very Easy → Hard

DFS = "go as deep as you can, then back up." It's basically recursion. Whenever a problem says height, diameter, path, same as another tree, balanced, BST property, LCA, or asks something about a subtree — DFS is the move.

VERY EASY D1. Maximum Depth of Binary Tree (LC 104)

Problem: Return the height of the tree (number of nodes from root to deepest leaf).

Intuition

"What's the height of this tree?" = "1 + the height of my taller child." Postorder: get child answers first, then combine.

public int maxDepth(TreeNode root){
    if (root == null) return 0;
    int l = maxDepth(root.left);
    int r = maxDepth(root.right);
    return 1 + Math.max(l, r);
}
This 4-line pattern (base case → recurse left → recurse right → combine) is the skeleton of most DFS tree problems. Tattoo it on your brain.

VERY EASY D2. Same Tree (LC 100)

Problem: Return true if two trees are structurally identical AND have equal values.

public boolean isSameTree(TreeNode p, TreeNode q){
    if (p == null && q == null) return true;     // both empty ✅
    if (p == null || q == null) return false;    // one empty, other not ❌
    if (p.val != q.val) return false;
    return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
}

EASY D3. Invert Binary Tree (LC 226)

Problem: Mirror the tree — for every node, swap its left and right children.

public TreeNode invertTree(TreeNode root){
    if (root == null) return null;
    TreeNode tmp = root.left;
    root.left  = invertTree(root.right);
    root.right = invertTree(tmp);
    return root;
}

Famous because Max Howell (creator of Homebrew) tweeted that Google rejected him for not being able to invert a binary tree on a whiteboard. Now you can.

EASY D4. Symmetric Tree (LC 101)

Problem: Is the tree a mirror image of itself around the center?

Intuition

Use a helper that compares two nodes — one walks left, the other walks right. They should always have equal values, and their kids should mirror each other.

public boolean isSymmetric(TreeNode root){
    return mirror(root.left, root.right);
}
private boolean mirror(TreeNode a, TreeNode b){
    if (a == null && b == null) return true;
    if (a == null || b == null) return false;
    return a.val == b.val
        && mirror(a.left,  b.right)    // outside vs outside
        && mirror(a.right, b.left);    // inside vs inside
}

EASY D5. Path Sum (LC 112)

Problem: Does any root‑to‑leaf path sum equal target?

Intuition

Subtract as you go. By the time you hit a leaf, ask: does the remaining target equal this leaf's value?

public boolean hasPathSum(TreeNode root, int target){
    if (root == null) return false;
    if (root.left == null && root.right == null)   // leaf!
        return target == root.val;
    return hasPathSum(root.left,  target - root.val)
        || hasPathSum(root.right, target - root.val);
}
Trap: A "leaf" means both children are null. Don't accept a node that has one missing child as a valid endpoint.

MEDIUM D6. Diameter of Binary Tree (LC 543)

Problem: Length of the longest path between any two nodes (counted in edges). The path doesn't need to pass through the root.

Intuition

For any node, the longest path that passes through it = height(left) + height(right). So while computing heights, also track the global max of L + R.

int best = 0;
public int diameterOfBinaryTree(TreeNode root){
    depth(root);
    return best;
}
private int depth(TreeNode n){
    if (n == null) return 0;
    int l = depth(n.left);
    int r = depth(n.right);
    best = Math.max(best, l + r);    // longest path THROUGH n
    return 1 + Math.max(l, r);     // height returned to parent
}
The "two-jobs" pattern: Recursion returns one thing (height) but also updates a global for another thing (diameter). You'll see this everywhere — diameter, max path sum, longest univalue path, etc.

MEDIUM D7. Lowest Common Ancestor (LC 236)

Problem: Given two nodes p and q, find the deepest node that is an ancestor of both.

Intuition (the "ping" idea)

Recurse. At each node:

  • If node == p || node == q, return node (we found one).
  • Recurse left and right.
  • If both sides come back non-null, this node is the split point — it's the LCA.
  • Otherwise, propagate whichever side is non-null up.
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q){
    if (root == null || root == p || root == q) return root;
    TreeNode l = lowestCommonAncestor(root.left,  p, q);
    TreeNode r = lowestCommonAncestor(root.right, p, q);
    if (l != null && r != null) return root;   // p and q split here
    return l != null ? l : r;                    // pass it up
}

MEDIUM D8. Validate Binary Search Tree (LC 98)

BST rule: For every node, all values in its left subtree are less, all values in its right subtree are greater. Recursively true.

Naive bug

Beginners check only node.left.val < node.val < node.right.val. That fails on:

5 / \ 4 6 / \ 3 7 ← 3 is in 5's RIGHT subtree but 3 < 5 ❌

Right fix: pass valid range down

public boolean isValidBST(TreeNode root){
    return valid(root, null, null);
}
private boolean valid(TreeNode n, Integer low, Integer high){
    if (n == null) return true;
    if (low  != null && n.val <= low)  return false;
    if (high != null && n.val >= high) return false;
    return valid(n.left,  low,  n.val)
        && valid(n.right, n.val, high);
}
Why Integer instead of int? Because the boundary can legitimately be Integer.MIN_VALUE or MAX_VALUE. Using a nullable Integer lets us say "no bound".

MEDIUM D9. All Root-to-Leaf Paths (LC 257)

Problem: Return all root‑to‑leaf paths as strings like "1->2->5".

Intuition

Backtracking! Carry a list of values down the recursion. When you hit a leaf, snapshot the path.

public List<String> binaryTreePaths(TreeNode root){
    List<String> ans = new ArrayList<>();
    if (root != null) go(root, new ArrayList<>(), ans);
    return ans;
}
private void go(TreeNode n, List<Integer> path, List<String> ans){
    path.add(n.val);
    if (n.left == null && n.right == null){
        StringBuilder sb = new StringBuilder();
        for (int i=0; i<path.size(); i++){
            if (i > 0) sb.append("->");
            sb.append(path.get(i));
        }
        ans.add(sb.toString());
    } else {
        if (n.left  != null) go(n.left,  path, ans);
        if (n.right != null) go(n.right, path, ans);
    }
    path.remove(path.size() - 1);   // 🔑 backtrack
}
The single most common DFS bug: forgetting to remove the last element on the way back up. Without it, the same path keeps growing across siblings.

HARD D10. Binary Tree Maximum Path Sum (LC 124)

Problem: A "path" is any sequence of nodes connected by parent-child edges. Find the path with the maximum value sum. The path doesn't need to start/end at root or leaf.

Intuition (the diameter pattern, leveled up)

For any node, the best path through it = node.val + max(0, leftGain) + max(0, rightGain). (We max(0, ...) because if a side gives negative gain, we skip it.) The function returns the best one-sided gain to the parent (only one side can extend upward).

int best = Integer.MIN_VALUE;
public int maxPathSum(TreeNode root){
    gain(root);
    return best;
}
private int gain(TreeNode n){
    if (n == null) return 0;
    int l = Math.max(0, gain(n.left));   // drop negatives
    int r = Math.max(0, gain(n.right));
    best = Math.max(best, n.val + l + r);  // path THROUGH n
    return n.val + Math.max(l, r);          // extend ONE side upward
}

HARD D11. Construct Tree from Preorder + Inorder (LC 105)

Problem: You're given the preorder and inorder arrays of a unique-valued tree. Rebuild the tree.

Intuition

  1. The first element of preorder is always the current root.
  2. Find that root's index in inorder. Everything left of it = left subtree's inorder. Everything right = right subtree's inorder.
  3. Recurse. Keep a moving pointer over preorder.
Map<Integer, Integer> idx;     // inorder value -> index
int pre = 0;
int[] preorder;

public TreeNode buildTree(int[] preorder, int[] inorder){
    this.preorder = preorder;
    idx = new HashMap<>();
    for (int i=0; i<inorder.length; i++) idx.put(inorder[i], i);
    return build(0, inorder.length - 1);
}
private TreeNode build(int inLeft, int inRight){
    if (inLeft > inRight) return null;
    int rootVal = preorder[pre++];
    TreeNode root = new TreeNode(rootVal);
    int mid = idx.get(rootVal);
    root.left  = build(inLeft, mid - 1);
    root.right = build(mid + 1, inRight);
    return root;
}
Why the HashMap? Without it, finding the root's index in inorder is O(n) per call → O(n²) total. The map makes it O(1) → O(n) total.

HARD D12. House Robber III (LC 337)

Problem: Houses arranged in a tree. If you rob a house, you can't rob its direct parent or direct children. Return the max money you can grab.

Intuition (DP on trees)

For each node, return a 2-element array [notRob, rob]:

  • rob = take this house's money + notRob from both children.
  • notRob = best of either choice from each child (you're free either way).
public int rob(TreeNode root){
    int[] r = dp(root);
    return Math.max(r[0], r[1]);
}
private int[] dp(TreeNode n){
    if (n == null) return new int[]{0, 0};
    int[] l = dp(n.left);
    int[] r = dp(n.right);
    int notRob = Math.max(l[0], l[1]) + Math.max(r[0], r[1]);
    int rob    = n.val + l[0] + r[0];
    return new int[]{notRob, rob};
}
Why this is the boss fight: It combines DFS + dynamic programming. If you understand this one, you can extend the same "return a tuple of states" trick to almost any tree DP problem.

    int r = dfs(n.right);
    globalAns = Math.max(globalAns, /* using both l and r */);
    return /* a single value to give the parent */;
}

Final mindset checklist before you write any tree code

  1. What's the base case? Almost always if (root == null) return …
  2. What does each recursive call promise to return? Decide this first. (a height? a boolean? a path list?)
  3. How do I combine left + right + current? That's the body of your function.
  4. Do I need a global / passed‑in accumulator? Yes for diameter, max-path-sum, paths, etc.
  5. Test on a 1-node tree, then a left-only chain, then a balanced one. 90% of bugs hide in these 3.
