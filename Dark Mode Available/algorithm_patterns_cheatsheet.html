01 Merge Intervals

Sort by start time, then linear scan to merge or compare consecutive intervals. The backbone of nearly every interval problem.

Core problem types

1Merging Overlapping Intervals
Merge all overlapping/touching intervals into a minimal non-overlapping set.
Classic: Merge Intervals
2Inserting an Interval
Insert a new interval into a sorted list of non-overlapping intervals and merge.
Classic: Insert Interval
3Removing Minimum Intervals
Remove the minimum number of intervals to make the rest non-overlapping.
Classic: Non-overlapping Intervals
4Finding Overlaps / Intersections
Find intersection between two lists of intervals.
Classic: Interval List Intersections
5Scheduling / Resource Allocation
Can attend all meetings? Min meeting rooms?
Meeting Rooms, Meeting Rooms II
6Interval Coverage / Bursting
Minimum points/arrows to cover or burst all intervals.
Min Number of Arrows to Burst Balloons
7Finding Gaps / Free Time
Find gaps between merged intervals (employee free time, etc.).

Other variants

  • Maximum Overlap Count (sweep line)
  • Merging with conditions (start/end logic variations)
  • Interval graph problems (greedy + sorting)
Key insight: Almost always sort by start time + linear scan. Mastering Merge, Insert, Non-overlapping, and Meeting Rooms II covers most variations.

Standard template (Java)

import java.util.*;

public class MergeIntervalsTemplate {

    /**
     * Standard template to merge overlapping intervals
     *
     * Time:  O(n log n) — due to sorting
     * Space: O(n)       — for the result list (worst case)
     */
    public int[][] merge(int[][] intervals) {
        if (intervals == null || intervals.length <= 1) {
            return intervals;
        }

        // Step 1: Sort intervals by start time — O(n log n)
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> merged = new ArrayList<>();

        // Step 2: Initialize with first interval
        int[] current = intervals[0];
        merged.add(current);

        // Step 3: Linear scan and merge — O(n)
        for (int i = 1; i < intervals.length; i++) {
            int[] next = intervals[i];

            if (current[1] >= next[0]) {
                // Overlap or touch — extend the end
                current[1] = Math.max(current[1], next[1]);
            } else {
                // No overlap — start a new interval
                current = next;
                merged.add(current);
            }
        }

        return merged.toArray(new int[merged.size()][]);
    }
}

More flexible / reusable template

public class IntervalUtils {

    /**
     * Reusable function to merge overlapping intervals.
     * Time: O(n log n)   Space: O(n)
     */
    public static List<int[]> mergeIntervals(int[][] intervals) {
        if (intervals == null || intervals.length == 0) {
            return new ArrayList<>();
        }

        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        List<int[]> result = new ArrayList<>();
        int[] curr = intervals[0].clone();   // clone to avoid mutating input

        for (int i = 1; i < intervals.length; i++) {
            int[] next = intervals[i];

            if (curr[1] >= next[0]) {            // overlapping / touching
                curr[1] = Math.max(curr[1], next[1]);
            } else {
                result.add(curr);
                curr = next.clone();
            }
        }
        result.add(curr);
        return result;
    }
}

02 Sliding Window

Two pointers (left & right) with expand / shrink logic. The right pointer always advances; left only shrinks when the condition breaks. Most variants run in O(N).

Core problem types

1Fixed Size Window
Window size is fixed (given k). Find max/min sum, average, distinct count.
Maximum Average Subarray I, Sliding Window Maximum
2Variable Size Window
Window expands and shrinks based on a condition. Smallest/largest subarray satisfying constraint.
Minimum Size Subarray Sum, Longest Substring Without Repeating
3Frequency Map / Counter
HashMap or array tracking character / element frequency.
Find All Anagrams, Minimum Window Substring
4Longest / Shortest with Constraint
At most K distinct chars, no repeating, with replacement, etc.
Longest Repeating Character Replacement
5Sum-Conditioned Subarrays
Sum equals K, at most K. Sliding window works for positive numbers.
6Max / Min in Sliding Window
Find max/min in every window of size k using a monotonic deque.
Sliding Window Maximum

Other variants

  • Counting valid windows (number of nice subarrays)
  • Two pointers + sliding window combos
  • Dynamic window with auxiliary DS (Deque, Set, TreeMap)
  • String permutation / anagram problems
  • Coverage / jump game variants
Heart of sliding window: right always expands, left only shrinks when condition violates, update answer when window is valid → O(N) guarantee.

Variable size template (recommended)

import java.util.*;

public class SlidingWindowTemplate {

    /**
     * Standard variable-size sliding window.
     * Time:  O(N) — each element visited at most twice
     * Space: O(1) or O(K) depending on aux storage
     */
    public int slidingWindowTemplate(int[] nums, int target) {
        int n = nums.length;
        int left = 0;
        int currentSum = 0;
        int result = Integer.MAX_VALUE;

        for (int right = 0; right < n; right++) {

            // 1. Expand: add current element
            currentSum += nums[right];

            // 2. Shrink while condition is violated
            while (currentSum > target && left <= right) {
                currentSum -= nums[left];
                left++;
            }

            // 3. Update result when window is valid
            if (currentSum == target) {
                result = Math.min(result, right - left + 1);
            }
        }

        return result == Integer.MAX_VALUE ? -1 : result;
    }
}

Fixed size template

/**
 * Fixed size sliding window (window size = k).
 * Time: O(N)   Space: O(1) or O(K)
 */
public int fixedSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    if (n < k) return 0;

    int left = 0;
    int currentSum = 0;

    // Build first window
    for (int i = 0; i < k; i++) currentSum += nums[i];
    int maxSum = currentSum;

    // Slide
    for (int right = k; right < n; right++) {
        currentSum += nums[right];   // add new
        currentSum -= nums[left];    // drop old
        left++;
        maxSum = Math.max(maxSum, currentSum);
    }
    return maxSum;
}

Frequency map template (string problems)

/**
 * Sliding window with HashMap counter.
 * Time: O(N)   Space: O(1) / O(26) / O(K)
 */
public int minWindowWithFrequency(String s, String t) {
    if (s.length() < t.length()) return 0;

    Map<Character, Integer> required = new HashMap<>();
    for (char c : t.toCharArray()) {
        required.put(c, required.getOrDefault(c, 0) + 1);
    }

    int left = 0, formed = 0;
    int minLen = Integer.MAX_VALUE;
    Map<Character, Integer> window = new HashMap<>();

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        window.put(c, window.getOrDefault(c, 0) + 1);

        if (required.containsKey(c) && window.get(c).equals(required.get(c))) {
            formed++;
        }

        // Shrink from left
        while (formed == required.size() && left <= right) {
            minLen = Math.min(minLen, right - left + 1);

            char leftChar = s.charAt(left);
            window.put(leftChar, window.get(leftChar) - 1);
            if (required.containsKey(leftChar) &&
                window.get(leftChar) < required.get(leftChar)) {
                formed--;
            }
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}

Core BST template (Java)

class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

public class BSTTemplates {

    // 1. SEARCH IN BST
    public TreeNode searchBST(TreeNode root, int val) {
        if (root == null || root.val == val) return root;
        return val < root.val
            ? searchBST(root.left, val)
            : searchBST(root.right, val);
    }

    // 2. VALIDATE BST — Time: O(n), Space: O(h)
    public boolean isValidBST(TreeNode root) {
        return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }
    private boolean validate(TreeNode node, long min, long max) {
        if (node == null) return true;
        if (node.val <= min || node.val >= max) return false;
        return validate(node.left,  min, node.val) &&
               validate(node.right, node.val, max);
    }

    // 3. Kth SMALLEST — Time: O(n), Space: O(h)
    private int count = 0;
    private int result = -1;
    public int kthSmallest(TreeNode root, int k) {
        count = 0;
        inorderKth(root, k);
        return result;
    }
    private void inorderKth(TreeNode node, int k) {
        if (node == null) return;
        inorderKth(node.left, k);
        if (++count == k) { result = node.val; return; }
        inorderKth(node.right, k);
    }

    // 4. INORDER TRAVERSAL — the king of BST patterns
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        inorderHelper(root, result);
        return result;
    }
    private void inorderHelper(TreeNode node, List<Integer> list) {
        if (node == null) return;
        inorderHelper(node.left, list);
        list.add(node.val);
        inorderHelper(node.right, list);
    }

    // 5. LOWEST COMMON ANCESTOR
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null) return null;
        if (p.val < root.val && q.val < root.val)
            return lowestCommonAncestor(root.left, p, q);
        if (p.val > root.val && q.val > root.val)
            return lowestCommonAncestor(root.right, p, q);
        return root;
    }
}

Short reference template

public class BSTTemplate {

    // 1. Search in BST (iterative)
    public TreeNode search(TreeNode root, int val) {
        while (root != null && root.val != val) {
            root = val < root.val ? root.left : root.right;
        }
        return root;
    }

    // 2. Validate BST
    public boolean isValidBST(TreeNode root) {
        return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }
    private boolean validate(TreeNode n, long min, long max) {
        if (n == null) return true;
        if (n.val <= min || n.val >= max) return false;
        return validate(n.left, min, n.val) && validate(n.right, n.val, max);
    }

    // 3. Kth Smallest
    int count = 0, ans = -1;
    public int kthSmallest(TreeNode root, int k) {
        count = 0; inorder(root, k); return ans;
    }
    private void inorder(TreeNode n, int k) {
        if (n == null) return;
        inorder(n.left, k);
        if (++count == k) ans = n.val;
        inorder(n.right, k);
    }

    // 4. LCA in BST
    public TreeNode lca(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null) return null;
        if (p.val < root.val && q.val < root.val) return lca(root.left, p, q);
        if (p.val > root.val && q.val > root.val) return lca(root.right, p, q);
        return root;
    }

    // 5. Inorder Traversal
    public List<Integer> inorderList(TreeNode root) {
        List<Integer> list = new ArrayList<>();
        helper(root, list);
        return list;
    }
    private void helper(TreeNode n, List<Integer> list) {
        if (n == null) return;
        helper(n.left, list);
        list.add(n.val);
        helper(n.right, list);
    }
}

04 Monotonic Deque / Stack

A stack or deque whose elements maintain a strict order (increasing or decreasing). Each element is pushed and popped at most once → amortized O(N). The go-to pattern for next greater / smaller element and sliding window max/min.

For each element find the next (or previous) greater / smaller value.

2Largest Rectangle in Histogram
Use a monotonic increasing stack to find the largest area rectangle.
Largest Rectangle in Histogram, Maximal Rectangle
3Sliding Window Max / Min
Find max/min in every window of size k using a monotonic deque.
Sliding Window Maximum
4Trapping Rain Water
Stack-based approach: pop when current bar is taller than stack top.
Trapping Rain Water
5Stock Span / Online Stock Span
For each day count consecutive days with price ≤ today.
Online Stock Span
6Sum of Subarray Minimums / Maximums
Contribution counting via prev/next smaller boundaries.
Sum of Subarray Minimums

Greedy stack — pop when current digit/char is smaller than top.
Remove K Digits, Remove Duplicate Letters

Pattern signal: if the problem asks for “next/previous greater/smaller”, “max/min in window”, or “how far back/forward until a bigger element”, reach for a monotonic structure first.

Monotonic stack template (Java)

import java.util.*;

public class MonotonicStackTemplate {

    /**
     * Next Greater Element to the right.
     * Returns ans[i] = next greater value, or -1 if none.
     *
     * Time:  O(N) — every index pushed and popped at most once
     * Space: O(N) — stack + result array
     */
    public int[] nextGreater(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        Arrays.fill(ans, -1);

        Deque<Integer> stack = new ArrayDeque<>();   // stores indices; values decreasing

        for (int i = 0; i < n; i++) {
            // While current is greater than stack top → resolve their answers
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                ans[stack.pop()] = nums[i];
            }
            stack.push(i);
        }
        // Indices left in the stack have no next greater → already -1
        return ans;
    }
}

Monotonic deque template (Sliding Window Max)

/**
 * Sliding Window Maximum using a monotonic decreasing deque.
 * Front of deque = index of current window's max.
 *
 * Time:  O(N)   Space: O(K)
 */
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] ans = new int[n - k + 1];
    Deque<Integer> dq = new ArrayDeque<>();   // stores indices; values decreasing

    for (int i = 0; i < n; i++) {

        // 1. Drop indices that fell out of the window
        if (!dq.isEmpty() && dq.peekFirst() <= i - k) {
            dq.pollFirst();
        }

        // 2. Maintain decreasing order from the back
        while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) {
            dq.pollLast();
        }

        dq.offerLast(i);

        // 3. Once first window is filled, record max
        if (i >= k - 1) {
            ans[i - k + 1] = nums[dq.peekFirst()];
        }
    }
    return ans;
}
Sliding window minimum: flip the comparison in step 2 to nums[dq.peekLast()] > nums[i]. Everything else stays the same.

Daily Temperatures (distance to next warmer day)

public int[] dailyTemperatures(int[] temps) {
    int n = temps.length;
    int[] ans = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {

        stack.push(i);
    }
    return ans;
}

Largest Rectangle in Histogram

public int largestRectangleArea(int[] h) {
    int n = h.length, maxArea = 0;
    Deque<Integer> stack = new ArrayDeque<>();   // increasing heights

    for (int i = 0; i <= n; i++) {
        int cur = (i == n) ? 0 : h[i];           // sentinel flushes stack at end
        while (!stack.isEmpty() && h[stack.peek()] > cur) {
            int height = h[stack.pop()];
            int width  = stack.isEmpty() ? i : i - stack.peek() - 1;
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    return maxArea;
}

Remove K Digits (greedy lexicographic)

public String removeKdigits(String num, int k) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : num.toCharArray()) {
        while (k > 0 && !stack.isEmpty() && stack.peek() > c) {
            stack.pop();
            k--;
        }
        stack.push(c);
    }
    while (k-- > 0 && !stack.isEmpty()) stack.pop();

    StringBuilder sb = new StringBuilder();
    while (!stack.isEmpty()) sb.append(stack.pollLast());
    while (sb.length() > 1 && sb.charAt(0) == '0') sb.deleteCharAt(0);
    return sb.length() == 0 ? "0" : sb.toString();
}
Hinglish quick guide — kaise use kare
  • Next Greater / Smaller → stack mein indices rakho, monotonic order maintain karo. Jab current top ko “resolve” kare to ans[top] = current.
  • Previous Greater / Smaller → push se pehle peek karo — jo bach gaya stack mein wahi previous greater/smaller hai.
  • Sliding Window Max → deque mein decreasing order rakho. Front always answer.
  • Largest Rectangle → increasing stack + sentinel (extra 0 at end) se sab flush karwao.
  • Daily Temperatures → next-greater wala template, bas ans[j] = i - j store karo distance ke liye.
  • Sum of Subarray Mins → PSE + NSE nikaal lo har index ka, contribution multiply karo.
  • Remove K Digits / Smallest Lexicographic → greedy stack: jab top > current ho aur k bacha ho, pop kar do.
  • Constrained Subsequence Sum → DP + deque, sirf valid range ke best dp values rakho.

Mantra: “Push only what helps the future. Pop everything that's now useless.” — har element at most ek baar push aur ek baar pop, isiliye total O(N).

Top K template — Kth Largest / K Most Frequent

/**
 * Kth Largest Element using a size-K min-heap.
 * Heap always holds the K largest seen so far → root is the Kth largest.
 *
 * Time:  O(N log K)
 * Space: O(K)
 */
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();

    for (int num : nums) {
        minHeap.offer(num);
        if (minHeap.size() > k) {
            minHeap.poll();   // drop smallest, keep top K
        }
    }
    return minHeap.peek();
}

/**
 * Top K Frequent Elements.
 * Time: O(N log K)   Space: O(N)
 */
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int n : nums) freq.merge(n, 1, Integer::sum);

    // Min-heap by frequency, size K
    PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    for (var e : freq.entrySet()) {
        heap.offer(new int[]{e.getKey(), e.getValue()});
        if (heap.size() > k) heap.poll();
    }

    int[] ans = new int[k];
    for (int i = k - 1; i >= 0; i--) ans[i] = heap.poll()[0];
    return ans;
}
Why size-K min-heap for Kth largest? The K largest elements live in the heap; the smallest of those (the root) is exactly the Kth largest overall. Keeping the heap bounded gives O(N log K) instead of O(N log N).

Two-heap template — Streaming Median

/**
 * Find Median from Data Stream.
 * lower = max-heap of the smaller half
 * upper = min-heap of the larger half
 * Invariant: lower.size() == upper.size() OR lower.size() == upper.size() + 1
 *
 * addNum:    O(log n)
 * findMedian: O(1)
 */
class MedianFinder {
    private final PriorityQueue<Integer> lower = new PriorityQueue<>(Comparator.reverseOrder());
    private final PriorityQueue<Integer> upper = new PriorityQueue<>();

    public void addNum(int num) {
        lower.offer(num);
        upper.offer(lower.poll());          // funnel through to keep ordering

        if (upper.size() > lower.size()) {  // rebalance
            lower.offer(upper.poll());
        }
    }

    public double findMedian() {
        if (lower.size() > upper.size()) return lower.peek();
        return (lower.peek() + upper.peek()) / 2.0;
    }
}

K-way merge — Merge K Sorted Lists

public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode head : lists) {
        if (head != null) pq.offer(head);
    }

    ListNode dummy = new ListNode(0), tail = dummy;
    while (!pq.isEmpty()) {
        ListNode node = pq.poll();
        tail.next = node;
        tail = node;
        if (node.next != null) pq.offer(node.next);
    }
    return dummy.next;
    // Time: O(N log K) where N = total nodes, K = number of lists
}

Meeting Rooms II — minimum rooms

public int minMeetingRooms(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    PriorityQueue<Integer> endTimes = new PriorityQueue<>();   // min-heap of end times

    for (int[] iv : intervals) {
        if (!endTimes.isEmpty() && endTimes.peek() <= iv[0]) {
            endTimes.poll();   // a room got freed → reuse
        }
        endTimes.offer(iv[1]);
    }
    return endTimes.size();
}

public int[][] kClosest(int[][] points, int k) {
    // Max-heap by distance; keep size K.
    PriorityQueue<int[]> heap = new PriorityQueue<>(
        (a, b) -> (b[0]*b[0] + b[1]*b[1]) - (a[0]*a[0] + a[1]*a[1])

        if (heap.size() > k) heap.poll();   // drop the farthest
    }

}

Dijkstra (single-source shortest path)

public int[] dijkstra(List<int[]>[] graph, int src) {
    int n = graph.length;
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;

    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, src});   // {distance, node}

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > dist[u]) continue;          // stale entry, skip

        for (int[] edge : graph[u]) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    return dist;
    // Time: O((V + E) log V)
}

Task Scheduler — frequency-based greedy

public int leastInterval(char[] tasks, int n) {
    int[] cnt = new int[26];
    for (char c : tasks) cnt[c - 'A']++;

    PriorityQueue<Integer> pq = new PriorityQueue<>(Comparator.reverseOrder());
    for (int c : cnt) if (c > 0) pq.offer(c);

    int time = 0;
    Queue<int[]> cooldown = new ArrayDeque<>();   // {remainingCount, availableTime}

    while (!pq.isEmpty() || !cooldown.isEmpty()) {
        time++;
        if (!pq.isEmpty()) {
            int remaining = pq.poll() - 1;
            if (remaining > 0) cooldown.offer(new int[]{remaining, time + n});
        }
        if (!cooldown.isEmpty() && cooldown.peek()[1] == time) {
            pq.offer(cooldown.poll()[0]);
        }
    }
    return time;
}

06 Dynamic Programming

Solve a problem by combining solutions to overlapping subproblems. Two ingredients: (1) a state that captures everything needed to make the next decision, and (2) a transition from smaller states to larger ones. Every DP can be written as either top-down memoization or bottom-up tabulation.

Core problem types

11D / Linear DP
Decision over a sequence; state depends on previous indices.
Climbing Stairs, House Robber, Decode Ways, LIS
22D / Grid DP
Path or count problems on a grid; state = (row, col).
Unique Paths, Min Path Sum, Maximal Square
3Knapsack (0/1 & Unbounded)
Pick items under a capacity constraint to optimize value/count.
0/1 Knapsack, Coin Change, Partition Equal Subset Sum, Target Sum
4String DP (LCS / Edit Distance)
Two-string alignment problems; state = (i, j).
LCS, Edit Distance, Distinct Subsequences, Wildcard / Regex Matching
5Interval DP
Solve sub-interval [i, j] by trying every split point k.
Burst Balloons, Matrix Chain Multiplication, Stone Game, Palindrome Partitioning II
6Bitmask DP
State includes a bitmask of visited / chosen items.
TSP, Partition to K Equal Sum Subsets, Shortest Path Visiting All Nodes
7Tree DP
Post-order recursion returning multiple values per node.
House Robber III, Diameter of Binary Tree, Max Path Sum, Binary Tree Cameras
8DP on Subsequences / Decision DP
At each index decide pick / skip / state-transition.
Best Time to Buy/Sell Stock series, Paint House, Delete and Earn

Other variants

  • Digit DP (count numbers with constraints in a range)
  • Probability / Expected value DP
  • DP + monotonic deque (Constrained Subsequence Sum, Jump Game VI)
  • DP + binary search (Russian Doll Envelopes, LIS in O(n log n))
  • Game-theory / Minimax DP (Stone Game, Predict the Winner)
How to recognize DP: the problem asks for a count, min/max, true/false, or optimal sequence, AND your decisions can be expressed as “at this position with this remaining budget, what is the best I can do?”. If subproblems repeat — it's DP.

The 5-step framework

  1. Define state: what does dp[i] (or dp[i][j]) mean in plain English?
  2. Recurrence: express dp[i] in terms of smaller states.
  3. Base case: what is the answer for the smallest subproblem?
  4. Iteration order: ensure dependencies are computed before they are used.
  5. Final answer: which cell holds the result? Sometimes it's dp[n], sometimes max(dp).

1D DP template — top-down & bottom-up

/**
 * Climbing Stairs / House Robber style — generic 1D template.
 *
 * State:      dp[i] = best answer using first i elements (or up to position i).
 * Recurrence: dp[i] = f(dp[i-1], dp[i-2], ..., dp[i-k])
 * Base:       dp[0], dp[1], ...
 * Time:       O(n)   Space: O(n) → can often be reduced to O(1)
 */
public int climbStairs(int n) {
    if (n <= 2) return n;

    // Bottom-up tabulation
    int prev2 = 1, prev1 = 2;
    for (int i = 3; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;     // O(1) space rolling variables
}

/**
 * Top-down memoization version — same recurrence, recursive form.
 */
Integer[] memo;
public int climbStairsMemo(int n) {
    memo = new Integer[n + 1];
    return solve(n);
}
private int solve(int n) {
    if (n <= 2) return n;
    if (memo[n] != null) return memo[n];
    return memo[n] = solve(n - 1) + solve(n - 2);
}

House Robber (decision DP)

// dp[i] = max money robbing houses [0..i]
// Choice: rob house i (dp[i-2] + nums[i]) or skip (dp[i-1])
public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int num : nums) {
        int cur = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

Longest Increasing Subsequence — O(n log n)

// tails[k] = smallest possible tail of an increasing subseq of length k+1
public int lengthOfLIS(int[] nums) {
    List<Integer> tails = new ArrayList<>();
    for (int x : nums) {
        int lo = 0, hi = tails.size();
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (tails.get(mid) < x) lo = mid + 1;
            else hi = mid;
        }
        if (lo == tails.size()) tails.add(x);
        else tails.set(lo, x);
    }
    return tails.size();
}

2D / Grid DP template

/**
 * Unique Paths / Min Path Sum style.
 *
 * State:      dp[i][j] = answer ending at cell (i, j)
 * Recurrence: dp[i][j] = combine(dp[i-1][j], dp[i][j-1])
 * Base:       first row / first column
 * Time:       O(m*n)   Space: O(m*n) → can be O(n) with rolling row
 */
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    dp[0][0] = grid[0][0];

    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = grid[i][j] + Math.min(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[m - 1][n - 1];
}

Maximal Square (largest all-1s square)

// dp[i][j] = side length of the largest square whose bottom-right corner is (i, j)
// dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1, when matrix[i][j] == '1'
public int maximalSquare(char[][] matrix) {
    int m = matrix.length, n = matrix[0].length, best = 0;
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (matrix[i - 1][j - 1] == '1') {
                dp[i][j] = Math.min(Math.min(dp[i - 1][j], dp[i][j - 1]), dp[i - 1][j - 1]) + 1;
                best = Math.max(best, dp[i][j]);
            }
        }
    }
    return best * best;
}

Knapsack templates

0/1 Knapsack (each item used at most once)

/**
 * 0/1 Knapsack: max value with capacity W, items have weight/value.
 *
 * dp[w] after processing item i = best value using a subset of {0..i} with total weight ≤ w
 * Iterate w from HIGH → LOW so each item is used at most once.
 *
 * Time: O(n * W)   Space: O(W)
 */
public int knapsack01(int[] weights, int[] values, int W) {
    int[] dp = new int[W + 1];

    for (int i = 0; i < weights.length; i++) {
        for (int w = W; w >= weights[i]; w--) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[W];
}

Unbounded Knapsack / Coin Change

/**
 * Coin Change — minimum coins to make amount.
 * Each coin can be used unlimited times.
 * Iterate w from LOW → HIGH so the same item can be reused.
 *
 * Time: O(n * amount)   Space: O(amount)
 */
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);   // sentinel for "impossible"
    dp[0] = 0;

    for (int coin : coins) {
        for (int a = coin; a <= amount; a++) {
            dp[a] = Math.min(dp[a], dp[a - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}

Subset Sum / Partition Equal Subset Sum

// Can we pick a subset summing to target?  → boolean 0/1 knapsack
public boolean canPartition(int[] nums) {
    int total = 0;
    for (int n : nums) total += n;
    if (total % 2 != 0) return false;
    int target = total / 2;

    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    for (int num : nums) {
        for (int s = target; s >= num; s--) {
            dp[s] = dp[s] || dp[s - num];
        }
    }
    return dp[target];
}
Direction rule of thumb: 0/1 knapsack iterates capacity downward (so each item is considered once); unbounded knapsack iterates capacity upward (so the same item can be reused).

String DP — LCS & Edit Distance

Longest Common Subsequence

/**
 * dp[i][j] = LCS length of s1[0..i-1] and s2[0..j-1]
 *
 * Recurrence:
 *   if s1[i-1] == s2[j-1]:  dp[i][j] = dp[i-1][j-1] + 1
 *   else:                   dp[i][j] = max(dp[i-1][j], dp[i][j-1])
 *
 * Time: O(m*n)   Space: O(m*n) → reducible to O(n)
 */
public int lcs(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}

Edit Distance (Levenshtein)

/**
 * dp[i][j] = min operations to convert s1[0..i-1] → s2[0..j-1]
 * Operations: insert, delete, replace.
 *
 * Time: O(m*n)   Space: O(m*n)
 */
public int minDistance(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 0; i <= m; i++) dp[i][0] = i;       // delete all
    for (int j = 0; j <= n; j++) dp[0][j] = j;       // insert all

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(
                    dp[i - 1][j - 1],                // replace
                    Math.min(dp[i - 1][j], dp[i][j - 1])   // delete / insert
                );
            }
        }
    }
    return dp[m][n];
}

Interval DP

/**
 * Interval DP — dp[i][j] = answer for sub-interval [i, j].
 * Recurrence tries every split point k between i and j.
 *
 * Iterate by increasing length so smaller intervals are solved first.
 *
 * Classic: Burst Balloons, Matrix Chain Multiplication, Stone Game.
 *
 * Time: O(n^3)   Space: O(n^2)
 */
public int matrixChainMultiplication(int[] dims) {
    int n = dims.length - 1;        // n matrices, dims has n+1 entries
    int[][] dp = new int[n][n];

    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k + 1][j] + dims[i] * dims[k + 1] * dims[j + 1];
                dp[i][j] = Math.min(dp[i][j], cost);
            }
        }
    }
    return dp[0][n - 1];
}

Burst Balloons (think backwards: k is the LAST balloon burst in [i, j])

public int maxCoins(int[] nums) {
    int n = nums.length;
    int[] arr = new int[n + 2];
    arr[0] = arr[n + 1] = 1;
    System.arraycopy(nums, 0, arr, 1, n);

    int[][] dp = new int[n + 2][n + 2];

    for (int len = 1; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            for (int k = i; k <= j; k++) {       // k = last balloon burst
                int gain = arr[i - 1] * arr[k] * arr[j + 1];
                dp[i][j] = Math.max(dp[i][j], dp[i][k - 1] + gain + dp[k + 1][j]);
            }
        }
    }
    return dp[1][n];
}

Bitmask DP

/**
 * Bitmask DP — state includes a bitmask of which items are "used".
 *
 * dp[mask] = best answer covering exactly the items represented by mask.
 *
 * Time: O(2^n * n)   Space: O(2^n)
 *
 * Use when n ≤ ~20.
 */
public int tsp(int[][] dist) {
    int n = dist.length;
    int[][] dp = new int[1 << n][n];
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0;        // start at node 0, only node 0 visited

    for (int mask = 1; mask < (1 << n); mask++) {
        for (int u = 0; u < n; u++) {
            if ((mask & (1 << u)) == 0) continue;
            for (int v = 0; v < n; v++) {
                if ((mask & (1 << v)) != 0) continue;
                int nextMask = mask | (1 << v);
                dp[nextMask][v] = Math.min(dp[nextMask][v], dp[mask][u] + dist[u][v]);
            }
        }
    }

    int best = Integer.MAX_VALUE;
    int full = (1 << n) - 1;
    for (int u = 1; u < n; u++) {
        best = Math.min(best, dp[full][u] + dist[u][0]);
    }
    return best;
}

Tree DP (post-order recursion)

/**
 * House Robber III — rob houses arranged as a binary tree without robbing
 * a parent and child both.
 *
 * For each node return a pair { robThis, skipThis }.
 *
 * Time: O(n)   Space: O(h) recursion
 */
public int rob(TreeNode root) {
    int[] ans = dfs(root);
    return Math.max(ans[0], ans[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};

    int[] left  = dfs(node.left);
    int[] right = dfs(node.right);

    int robThis  = node.val + left[1] + right[1];                   // can't rob children
    int skipThis = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);

    return new int[]{robThis, skipThis};
}

Diameter / Max Path Sum pattern

// Standard tree-DP shape:
//   1. recurse left, recurse right
//   2. update a global answer using both children
//   3. RETURN only what the parent can extend (single arm)
int best = 0;
int dfsDiameter(TreeNode node) {
    if (node == null) return 0;
    int l = dfsDiameter(node.left);
    int r = dfsDiameter(node.right);
    best = Math.max(best, l + r);            // path through node
    return 1 + Math.max(l, r);               // single arm extends upward
}

Top-down ↔ Bottom-up conversion

  • Write the recursive solution first → identify state parameters → that's your dp[...] shape.
  • Add memoization with a map / array of the same shape — this is top-down.
  • Flip the order of computation (smallest state first) and replace recursion with loops — this is bottom-up.
  • If only the last k rows / columns are needed, compress space with rolling arrays.

  • 2D Grid DP — Unique Paths, Min Path Sum. dp[i][j] = combine(dp[i-1][j], dp[i][j-1]).

Mantra: “Define state in plain English, write recurrence, decide order, optimize space.” 90% DP problems is framework se solve ho jaate hain.

07 Tree (Binary Tree, General)

Binary tree problems are dominated by two ideas: (1) recursion that returns information from subtrees, and (2) BFS/level-order traversal with a queue. Almost every tree problem reduces to choosing the right traversal and the right "what does this subtree return?".

DFS traversals (recursive & iterative)

class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

public class TreeTraversals {

    /* ---------------- Recursive ---------------- */
    public void preorder(TreeNode node, List<Integer> out) {
        if (node == null) return;
        out.add(node.val);                 // visit
        preorder(node.left, out);
        preorder(node.right, out);
    }

    public void inorder(TreeNode node, List<Integer> out) {
        if (node == null) return;
        inorder(node.left, out);
        out.add(node.val);                 // visit
        inorder(node.right, out);
    }

    public void postorder(TreeNode node, List<Integer> out) {
        if (node == null) return;
        postorder(node.left, out);
        postorder(node.right, out);
        out.add(node.val);                 // visit
    }

    /* ---------------- Iterative inorder (stack) ---------------- */
    public List<Integer> inorderIterative(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;

        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();
            out.add(cur.val);
            cur = cur.right;
        }
        return out;
    }

    /* ---------------- Iterative preorder ---------------- */
    public List<Integer> preorderIterative(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        if (root == null) return out;
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode n = stack.pop();
            out.add(n.val);
            if (n.right != null) stack.push(n.right);   // right first → left popped first
            if (n.left  != null) stack.push(n.left);
        }
        return out;
    }
}
Time: O(n) for any traversal. Space: O(h) for the recursion / explicit stack — O(log n) on a balanced tree, O(n) worst case (skewed). Morris Traversal achieves O(1) extra space.

BFS / Level-order template

/**
 * Level-order traversal — group nodes by depth.
 *
 * Time: O(n)   Space: O(w) where w = max width of the tree
 */
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();                 // freeze the level
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}

Right Side View (BFS, last node per level)

public List<Integer> rightSideView(TreeNode root) {
    List<Integer> out = new ArrayList<>();
    if (root == null) return out;

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode n = queue.poll();
            if (i == size - 1) out.add(n.val);   // last node of this level
            if (n.left  != null) queue.offer(n.left);
            if (n.right != null) queue.offer(n.right);
        }
    }
    return out;
}

Zigzag Level Order

// Same BFS skeleton, but on alternate levels reverse the level list (or use a deque).
public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> out = new ArrayList<>();
    if (root == null) return out;

    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    boolean ltr = true;

    while (!q.isEmpty()) {
        int size = q.size();
        LinkedList<Integer> level = new LinkedList<>();
        for (int i = 0; i < size; i++) {
            TreeNode n = q.poll();
            if (ltr) level.addLast(n.val);
            else     level.addFirst(n.val);
            if (n.left  != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
        out.add(level);
        ltr = !ltr;
    }
    return out;
}

Core recursion patterns

Pattern A — Bottom-up: return one value per subtree

// Max Depth — classic bottom-up recursion
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

Pattern B — Bottom-up + global answer (Diameter / Max Path Sum)

/**
 * Diameter of Binary Tree.
 * Each call returns the height (single arm).
 * The "diameter through this node" updates a global best.
 */
private int best = 0;

public int diameterOfBinaryTree(TreeNode root) {
    best = 0;
    height(root);
    return best;
}

private int height(TreeNode node) {
    if (node == null) return 0;
    int l = height(node.left);
    int r = height(node.right);
    best = Math.max(best, l + r);     // path through this node
    return 1 + Math.max(l, r);        // single arm extends upward
}

Pattern C — Top-down: pass info down via parameters

// Path Sum — does any root-to-leaf path sum to target?
public boolean hasPathSum(TreeNode root, int target) {
    if (root == null) return false;
    if (root.left == null && root.right == null) {
        return target == root.val;
    }
    int rest = target - root.val;
    return hasPathSum(root.left, rest) || hasPathSum(root.right, rest);
}

Pattern D — Multi-return tuple (Tree DP)

/**
 * House Robber III — return { robThis, skipThis }
 * Time: O(n)   Space: O(h)
 */
public int rob(TreeNode root) {
    int[] ans = robDfs(root);
    return Math.max(ans[0], ans[1]);
}

private int[] robDfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] l = robDfs(node.left);
    int[] r = robDfs(node.right);

    int rob  = node.val + l[1] + r[1];                          // can't rob children
    int skip = Math.max(l[0], l[1]) + Math.max(r[0], r[1]);     // children free
    return new int[]{rob, skip};
}

Pattern E — Maximum Path Sum (any-to-any path)

private int maxSum = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    maxSum = Integer.MIN_VALUE;
    gain(root);
    return maxSum;
}

private int gain(TreeNode node) {
    if (node == null) return 0;
    int l = Math.max(0, gain(node.left));     // ignore negative gains
    int r = Math.max(0, gain(node.right));
    maxSum = Math.max(maxSum, node.val + l + r);
    return node.val + Math.max(l, r);          // single arm continues up
}

Lowest Common Ancestor (general binary tree)

/**
 * LCA without BST ordering.
 * Idea: recurse left and right; if both sides return non-null, current node is LCA.
 *
 * Time: O(n)   Space: O(h)
 */
public TreeNode lca(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;

    TreeNode left  = lca(root.left,  p, q);
    TreeNode right = lca(root.right, p, q);

    if (left != null && right != null) return root;   // p and q split here
    return left != null ? left : right;
}

Construction from traversals

/**
 * Build tree from Preorder + Inorder.
 * preorder[0] is the root; locate it in inorder to split left/right subtrees.
 *
 * Time: O(n) using a HashMap of inorder index lookups
 * Space: O(n)
 */
private Map<Integer, Integer> inIndex;
private int preIdx;

public TreeNode buildTree(int[] preorder, int[] inorder) {
    inIndex = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) inIndex.put(inorder[i], i);
    preIdx = 0;
    return build(preorder, 0, inorder.length - 1);
}

private TreeNode build(int[] preorder, int inLeft, int inRight) {
    if (inLeft > inRight) return null;

    int rootVal = preorder[preIdx++];
    TreeNode root = new TreeNode(rootVal);
    int mid = inIndex.get(rootVal);

    root.left  = build(preorder, inLeft, mid - 1);
    root.right = build(preorder, mid + 1, inRight);
    return root;
}

Serialize / Deserialize (preorder + null markers)

public class Codec {

    private static final String NULL = "#";
    private static final String SEP  = ",";

    // ---- Serialize: preorder DFS, write "#" for null ----
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        serializeDfs(root, sb);
        return sb.toString();
    }

    private void serializeDfs(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append(NULL).append(SEP);
            return;
        }
        sb.append(node.val).append(SEP);
        serializeDfs(node.left, sb);
        serializeDfs(node.right, sb);
    }

    // ---- Deserialize: consume tokens in preorder ----
    public TreeNode deserialize(String data) {
        Deque<String> tokens = new ArrayDeque<>(Arrays.asList(data.split(SEP)));
        return deserializeDfs(tokens);
    }

    private TreeNode deserializeDfs(Deque<String> tokens) {
        String t = tokens.poll();
        if (t == null || t.equals(NULL)) return null;
        TreeNode node = new TreeNode(Integer.parseInt(t));
        node.left  = deserializeDfs(tokens);
        node.right = deserializeDfs(tokens);
        return node;
    }
}

Invert Binary Tree

public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode left  = invertTree(root.left);
    TreeNode right = invertTree(root.right);
    root.left  = right;
    root.right = left;

Flatten Binary Tree to Linked List (preorder, in-place)

// Iterative variant: for each node, attach right subtree to the rightmost
// of the left subtree, then move left to right.
public void flatten(TreeNode root) {
    TreeNode cur = root;
    while (cur != null) {
        if (cur.left != null) {
            TreeNode rightmost = cur.left;
            while (rightmost.right != null) rightmost = rightmost.right;
            rightmost.right = cur.right;
            cur.right = cur.left;
            cur.left  = null;
        }
        cur = cur.right;
    }
}

Same Tree / Symmetric Tree

public boolean isSameTree(TreeNode p, TreeNode q) {
    if (p == null || q == null) return p == q;
    return p.val == q.val
        && isSameTree(p.left,  q.left)
        && isSameTree(p.right, q.right);
}

public boolean isSymmetric(TreeNode root) {
    return root == null || mirror(root.left, root.right);
}
private boolean mirror(TreeNode a, TreeNode b) {
    if (a == null || b == null) return a == b;
    return a.val == b.val
        && mirror(a.left,  b.right)
        && mirror(a.right, b.left);
}

Quick checklist for any tree problem

  1. What does each subtree return? (height, sum, count, boolean, tuple…)
  2. Top-down or bottom-up information flow?
  3. Do I need a global variable, or can the answer be folded into the return?
  4. What is the base case? (node == null, leaf, single node)
  5. Will iteration be cleaner (BFS / iterative DFS) or is recursion fine?

  • Height / Depth / Count → Pattern A: bottom-up, sirf ek number return karo.
  • Diameter / Max Path Sum → Pattern B/E: subtree se single arm return karo, global best update karo "through this node" wale path se.
