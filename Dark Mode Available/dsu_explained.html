Level 1

Very Easy — The Friend Group Idea

Imagine your school. There are 6 students: 0, 1, 2, 3, 4, 5. At the start of the year nobody knows each other — they're all in their own little bubble.

🎯 Core Idea DSU (Disjoint Set Union) answers ONE question super fast:
"Are these two people in the same friend group?"

It can also merge two groups together: "0 and 1 just became friends — join their groups!"

DSU tracks two operations:

  1. find(x) — find the "boss" (representative) of x's group
  2. union(x, y) — merge the groups of x and y
DSU.java — Simplest version (array of parents)
int[] parent = new int[6]; // 6 students: 0..5

// At start everyone is their OWN parent (own group)
for (int i = 0; i < 6; i++) {
    parent[i] = i;
}
// parent = [0, 1, 2, 3, 4, 5]
//          ↑  ↑  ↑  ↑  ↑  ↑
//       each is their own boss!
💡 Think of it like this If parent[x] == x, then x is the boss (root) of their group. Otherwise, x's boss is parent[x].
Level 2

Easy — find() and union()

Now let's write the two core functions.

find(x) — keeps following parent pointers until it reaches the root:

DSU.java — find() function
int find(int[] parent, int x) {
    if (parent[x] == x) {
        return x; // x is the boss! stop here.
    }
    return find(parent, parent[x]); // go up the chain
}

union(x, y) — makes one group's boss point to the other's boss:

DSU.java — union() function
void union(int[] parent, int x, int y) {
    int bossX = find(parent, x);
    int bossY = find(parent, y);
    parent[bossX] = bossY; // bossX now reports to bossY
}

// Check if same group:
boolean connected(int[] parent, int x, int y) {
    return find(parent, x) == find(parent, y);
}
🔁 Example walkthrough union(0,1) → find boss of 0 = 0, find boss of 1 = 1 → set parent[0] = 1
union(1,2) → find boss of 1 = 1, find boss of 2 = 2 → set parent[1] = 2
connected(0,2) → find(0) follows 0→1→2 = 2, find(2) = 2 → YES, same group ✅
Level 3

Very Medium — Making it Fast

The naive DSU can be SLOW. Imagine a chain: 0→1→2→3→4→5. Finding the boss of 0 takes 5 steps. If we had 10,000 nodes, that's painful.

We fix this with two clever tricks:

Trick 1 — Path Compression 🗜️

After finding the root, make EVERY node on the path point directly to the root. Next time it's O(1)!

DSU.java — find() with Path Compression
int find(int[] parent, int x) {
    if (parent[x] != x) {
        // 🔥 The magic line — point directly to root
        parent[x] = find(parent, parent[x]);
    }
    return parent[x];
}

Trick 2 — Union by Rank 🏋️

When merging two groups, always attach the shorter tree under the taller one. This keeps trees flat.

DSU.java — Complete DSU with both optimizations
class DSU {
    int[] parent, rank;

    DSU(int n) {
        parent = new int[n];
        rank   = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        // rank[] starts all 0 (height = 0)
    }

    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]); // path compression
        return parent[x];
    }

    void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return; // already same group!

        // Attach smaller rank under bigger rank
        if      (rank[rx] < rank[ry]) parent[rx] = ry;
        else if (rank[rx] > rank[ry]) parent[ry] = rx;
        else {
            parent[ry] = rx;
            rank[rx]++;  // same height → one grows by 1
        }
    }

    boolean connected(int x, int y) {
        return find(x) == find(y);
    }
}
Time per operation: ≈ O(α(n)) — that's practically O(1), the fastest possible!
🤓 What is α(n)? It's the inverse Ackermann function. For ANY real-world input (even n = 10^80), α(n) ≤ 4. So we call it "effectively constant."
Level 4

Medium — Classic Problems

Now let's use DSU to solve real problems!

Problem 1 — Number of Connected Components

Given n nodes and a list of edges, how many separate groups (components) exist?

NumberOfComponents.java — LeetCode #323 style
int countComponents(int n, int[][] edges) {
    DSU dsu = new DSU(n);
    int components = n; // Start: everyone is separate

    for (int[] edge : edges) {
        int u = edge[0], v = edge[1];
        if (!dsu.connected(u, v)) {
            dsu.union(u, v);
            components--; // Two groups merged → one less
        }
    }
    return components;
}

// Example:
// n=5, edges = [[0,1],[1,2],[3,4]]
// Result: 2  ({0,1,2} and {3,4})

Problem 2 — Detect Cycle in Undirected Graph

If we try to union two nodes that are ALREADY in the same group, that means there's a cycle!

CycleDetection.java
boolean hasCycle(int n, int[][] edges) {
    DSU dsu = new DSU(n);

    for (int[] edge : edges) {
        int u = edge[0], v = edge[1];
        if (dsu.connected(u, v)) {
            return true; // 🚨 Already same group → CYCLE!
        }
        dsu.union(u, v);
    }
    return false;
}

// Why does this work?
// An edge between two already-connected nodes
// creates a second path → that's a cycle!

Problem 3 — Kruskal's MST (Minimum Spanning Tree)

Find the cheapest set of edges to connect all nodes. DSU is the backbone of Kruskal's algorithm!

KruskalMST.java
int minimumSpanningTree(int n, int[][] edges) {
    // edges[i] = {cost, u, v}
    Arrays.sort(edges, (a, b) -> a[0] - b[0]); // sort by cost
    DSU dsu = new DSU(n);
    int totalCost = 0, edgesUsed = 0;

    for (int[] e : edges) {
        int cost = e[0], u = e[1], v = e[2];
        if (!dsu.connected(u, v)) {  // don't create cycle
            dsu.union(u, v);
            totalCost += cost;
            edgesUsed++;
        }
        if (edgesUsed == n - 1) break; // MST complete
    }
    return totalCost;
}
🌟 Greedy idea Always pick the cheapest edge that doesn't create a cycle. DSU detects cycles in ~O(1) — perfect for this!

Level 5

Hard — Advanced DSU Tricks

This is where DSU gets really clever. These techniques appear in competitive programming and tough interviews.

Trick 1 — Weighted DSU (store extra info)

We can store a weight/offset for each node relative to its parent. Useful for problems like: "A is 3 heavier than B. B is 2 heavier than C. How much heavier is A than C?"

WeightedDSU.java — relative weights
class WeightedDSU {
    int[] parent;
    long[] weight; // weight[x] = difference from x to parent[x]

    WeightedDSU(int n) {
        parent = new int[n];
        weight = new long[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    // Returns {root, accumulated weight from x to root}
    long find(int x) {
        if (parent[x] == x) return 0;
        long w = find(parent[x]);
        parent[x] = parent[parent[x]]; // path compression
        weight[x] += w;
        return weight[x];
    }

    // Union with: value[x] - value[y] = diff
    void union(int x, int y, long diff) {
        long wx = find(x), wy = find(y);
        int rx = parent[x], ry = parent[y];
        if (rx == ry) return;
        parent[rx] = ry;
        weight[rx] = wy - wx + diff;
    }
}

Trick 2 — Rollback DSU (undo operations)

Sometimes you need to undo a union — e.g., divide-and-conquer on graphs or offline queries. We give up path compression but keep union by rank, and use a stack to record changes.

RollbackDSU.java — undo-able unions
class RollbackDSU {
    int[] parent, rank;
    Deque<int[]> history = new ArrayDeque<>();

    RollbackDSU(int n) {
        parent = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int x) { // NO path compression (needed for rollback)
        return parent[x] == x ? x : find(parent[x]);
    }

    void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) { history.push(new int[]{-1,-1,-1,-1}); return; }
        if (rank[rx] < rank[ry]) { int t=rx; rx=ry; ry=t; }
        // Save old state before changing
        history.push(new int[]{ry, parent[ry], rx, rank[rx]});
        parent[ry] = rx;
        if (rank[rx] == rank[ry]) rank[rx]++;
    }

    void rollback() { // undo last union
        int[] snap = history.pop();
        if (snap[0] == -1) return; // was a no-op
        parent[snap[0]] = snap[1]; // restore parent
        rank[snap[2]]   = snap[3]; // restore rank
    }
}

Trick 3 — Offline Dynamic Connectivity

When edges can be added AND deleted (not just added), we use a segment-tree-on-time + Rollback DSU combo. Each edge "exists" from time L to time R — we insert it into the segment tree, then DFS the segment tree running union/rollback:

DynamicConnectivity.java — concept skeleton
// Segment tree over time slots 0..Q-1
List<int[]>[] segtree = new List[4 * Q];

void add(int node, int l, int r, int ql, int qr, int[] edge) {
    if (ql > r || qr < l) return;
    if (ql <= l && r <= qr) { segtree[node].add(edge); return; }
    int mid = (l + r) / 2;
    add(node*2, l, mid, ql, qr, edge);
    add(node*2+1, mid+1, r, ql, qr, edge);
}

void solve(int node, int l, int r) {
    // Union all edges at this node
    for (int[] e : segtree[node]) dsu.union(e[0], e[1]);

    if (l == r) {
        answer[l] = dsu.connected(query[l][0], query[l][1]);
    } else {
        int mid = (l + r) / 2;
        solve(node*2, l, mid);
        solve(node*2+1, mid+1, r);
    }

    // Rollback all unions at this node
    for (int i = 0; i < segtree[node].size(); i++) dsu.rollback();
}
⚡ Complexity This handles Q queries with edge additions and deletions in O(Q log Q · α(N)) — much better than re-running BFS/DFS for each query which would be O(Q · N)!
