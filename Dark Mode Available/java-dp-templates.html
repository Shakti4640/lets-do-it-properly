// quick reference

Linear DP

Statedp[i] = best for first i
Depends ondp[i-1], dp[i-2]
Space optTwo variables
ExamplesHouse robber, stairs

0/1 Knapsack

Statedp[i][w]
Depends ondp[i-1][w], dp[i-1][w-wt]
Space opt1D, iterate reverse
ExamplesKnapsack, subset sum

2-Sequence (LCS)

Statedp[i][j] two prefixes
Depends ondiagonal or adjacent cell
Space optTwo rows
ExamplesLCS, edit distance

Interval DP

Statedp[i][j] range [i,j]
Fill orderShort → long intervals
ComplexityO(n³) time, O(n²) space
ExamplesMatrix chain, balloons

DP on DAG

Statedp[node] best path
Fill orderTopological order
LIS fastO(n log n) binary search
ExamplesLIS, longest DAG path

Bitmask DP

Statedp[mask] subset
ComplexityO(2ⁿ · n)
Constraintn ≤ 20 typically
ExamplesTSP, task assignment
